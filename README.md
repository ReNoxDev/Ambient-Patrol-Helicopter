# Ambient-Patrol-Mods

Ambient Patrol Helicopter :
adds an immersive airborne encounter that patrols the world, circles survivors and POIs, hunts zombies, scans the night with a spotlight, and can be fought for valuable crash-site loot. Includes custom audio, combat, scaling difficulty, and airdrops.


Ambient Patrol Jeep :
adds an immersive ground encounter that patrols the world, circles survivors and POIs, hunts zombies, Jeep comes with head lights as well as a radio with a few royalty free tracks, and can be fought for valuable loot, though youll have to beat its passengers after you take down the jeep. Includes custom audio, combat, scaling difficulty, and airdrops.
For now it will be zombies pre-bandit Update. When bandits are live I will swap in bandits for the main Update and keep the zombies version as an encounter for early game so bandits dont overwhelm you.
